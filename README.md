# Dashboard Telebrasil

Dashboard demonstrativo para trabalho escolar. Aplicação estática em HTML, CSS e JavaScript, sem backend ou banco de dados.

## Como abrir

Abra `index.html` em um navegador. Na tela de acesso, use qualquer usuário e senha.

## Funcionalidades

- Resumo e estatísticas dos clientes
- Busca por nome, CNPJ ou cidade e filtros por consultor e status
- Cadastro de clientes, vendedores e planos
- Exportação da lista de clientes para CSV compatível com Excel
- Persistência dos cadastros no armazenamento local do navegador

Os dados de exemplo são fictícios. Os cadastros ficam no navegador em que a aplicação foi aberta e não são enviados a um servidor.
