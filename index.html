Como usar o dashboard

Guia rápido para consultar clientes e manter os cadastros organizados.

1. Acessar o painel

Informe qualquer usuário e senha na tela inicial para entrar no modo demonstrativo. Use “Sair” no cabeçalho para voltar à tela de acesso.

2. Consultar clientes

No painel, veja os indicadores no topo. Use a busca por nome, CNPJ ou cidade e os filtros de consultor e status para localizar clientes. Os cartões mostram contato, linhas, notas e situação.

3. Atualizar acompanhamento

Escreva observações no campo “Notas e status”. Marque “Visto” quando revisar o cliente e use “Ganho” ou “Perdido” para atualizar a oportunidade. Os indicadores acompanham essas alterações.

4. Exportar clientes

Selecione “Baixar Excel” para baixar a lista de clientes em CSV, que pode ser aberto no Excel ou em outro editor de planilhas.

5. Cadastrar informações

Abra “Cadastros” e escolha uma das quatro abas. Cadastre o cliente com seus dados e endereço; depois, use “Cadastro de Contratação” para associá-lo ao vendedor e ao plano.

6. Dados e armazenamento

Os registros ficam salvos no armazenamento local deste navegador e dispositivo. Eles permanecem após atualizar a página, mas não são sincronizados entre dispositivos ou navegadores.

Este dashboard é uma demonstração escolar com dados fictícios. Evite inserir informações pessoais reais.
